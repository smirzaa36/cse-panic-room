# CSE Panic Room

A browser-based study dashboard designed to help organize revision and practise CSE topics.

## Overview

Choose a CSE subject, break revision into manageable missions, and use the built-in study tools to practise.

## What you can use

- **Mission board:** Choose from AI & Machine Learning, Data Structures, Database Systems, and Operating Systems.
- **Revision checklist:** Track completed missions, add a mission, or reset the checklist.
- **Progress summary:** View the number of missions completed and the completion percentage.
- **Emergency focus sprint:** Run a 10, 15, or 25-minute focus timer.
- **Flash-card pit stop:** Review cards using previous/next controls and shuffle the deck.
- **Pop viva:** Practise with short quiz questions.
- **Theme switcher:** Switch between light and dark themes.
- **Encouragement prompt:** Use the pep-talk control when you need a little motivation.

## How to run

1. Download `cse-panic-room.html`.
2. Open the file in a modern web browser.
3. Select a subject and start using the dashboard.

No installation or build step is required.

## Note

The page indicates that checklist progress stays in the browser on the device where it is used. It is a personal study aid; it does not replace your course material or official syllabus.
